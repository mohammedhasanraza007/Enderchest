# The release zip: the smallest set of committed files that build.bat and run.bat need.
# Git pathspecs, one per line; ":(exclude)" lines drop files from the line above them.
# Docs, tests, logs, history and dev tools stay in the repo. Build (Git Bash, from the repo root):
#   grep -v '^#' release/files.txt | tr -d '\r' | xargs -d '\n' git archive --format=zip \
#     --prefix=Enderchest/ --add-file=release/README.md -o <zip> HEAD --
# release/README.md becomes the zip's Enderchest/README.md (the repo's README is the pack's).
